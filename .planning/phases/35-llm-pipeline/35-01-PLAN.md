<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Document text → LLM API | Chunk text is sent to external OpenRouter API (by design — this is the pipeline's purpose). The LLM sees all document content. |
| LLM API → Backend | Parsed JSON output crosses from external service into the pipeline; all fields are validated against JSON schema before storage. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-35-01 | Tampering | Prompt injection via document text | mitigate | Document text could contain instructions that hijack LLM behavior or produce malformed JSON. Mitigation: validate LLM response is valid JSON matching `EVENT_EXTRACTION_SCHEMA_V7` at the `_parse_choice` level; reject responses that don't parse or don't conform to schema shape; do NOT pass response directly to any execution context (DB writes use parameterized queries) |
| T-35-02 | Tampering | LLM output SQL injection | mitigate | All database writes use asyncpg parameterized queries (`$1, $2, ...`). LLM-generated title, description, and verbatim_text values are NEVER interpolated into SQL strings — only bound as parameters. |
| T-35-03 | Information Disclosure | API key exposure in logs | accept | The existing `OpenRouterProvider` already logs only the last 8 characters of the Authorization header. No new logging surfaces the full key. Accepted risk level: low. |
| T-35-04 | Denial of Service | Cost exhaustion via Temporal replay | mitigate | Temporal replays re-execute the LLM API call, incurring cost each time. Mitigation: max 3 retry attempts per chunk (existing RetryPolicy), `temperature=0.0` to minimize output variation, short retry windows. The per-chunk commit pattern means only the failed chunk is replayed, not the entire document. |
| T-35-05 | Denial of Service | Non-JSON LLM response crashes activity | mitigate | The `_parse_choice` method already raises RuntimeError for non-JSON content. The `extract_events_v7_activity` catches this and returns a degraded result `{"events": [], "refused": ...}` rather than crashing. The workflow continues to the next chunk. |
| T-35-06 | Information Disclosure | Data exfiltration through LLM prompts | accept | Document text is intentionally sent to the external OpenRouter API — this is the pipeline's core function. No user PII beyond the document content itself is sent. The user controls which documents they upload and process. Accepted risk: inherent to the feature. |
| T-35-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in this phase; all dependencies (temporalio, asyncpg, httpx, sqlalchemy) are established in prior phases with verified packages. |
</threat_model>
