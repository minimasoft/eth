    **Class 1: TestBalancedDistribution (CHK-01)**
    - `test_single_chunk_short_text()`: `SmartChunker(target_size=1000).chunk("Hello. World.", [0, 14])` returns 1 chunk
    - `test_multi_chunk_balanced()`: text of 100 short sentences (each 100 chars), target_size=3000. Assert that no chunk exceeds 1.5× target and no chunk (except possibly last if total text < 2× target) is below 0.5× target when >1 chunk
    - `test_two_chunks_reasonably_balanced()`: text of 4000 chars, target_size=2500. Assert exactly 2 chunks, both sizes within [1250, 3750] (0.5× to 1.5× target)
    - `test_balanced_distribution_function_directly()`: call `distribute_balanced(["a", "b", "c", "d"], [1, 1, 1, 1], target_size=2)`. Assert returns [[0, 1], [2, 3]] — 2 chunks, 2 sentences each

    **Class 2: TestSentenceBoundaries (CHK-02)**
    - `test_boundaries_not_mid_word()`: chunk text with sentences ending in `. ` and verify each chunk text ends with `.` followed by whitespace or EOS
    - `test_each_chunk_starts_at_sentence()`: for each chunk, verify its `offset_start` maps to the start of a sentence in the original text (capital letter or whitespace preceding)
    - `test_paragraph_boundary_respected()`: text with `\n\n` between paragraphs — verify no chunk splits a paragraph unnaturally (chunk boundary falls at paragraph break, not within a paragraph, when possible)
    - `test_empty_text()`: `SmartChunker().chunk("", [0])` returns 1 chunk with text="" and offset_start=0, offset_end=0

    **Class 3: TestSpanishAbbreviations (CHK-02)**
    - `test_sl_does_not_split()`: `"La empresa S.L. firmó el contrato. Otra frase."` → exactly 2 sentence spans from the tokenizer
    - `test_art_does_not_split()`: `"Según el art. 15 de la Ley. Continúa el texto."` → exactly 2 sentence spans
    - `test_dr_does_not_split()`: `"El Dr. García declaró. El fiscal preguntó."` → exactly 2 sentence spans
    - `test_multiple_abbreviations_in_one_sentence()`: `"La empresa S.L. y el Dr. García comparecieron en el art. 15."` → exactly 1 sentence span (all abbreviations within one actual sentence)
    - `test_legal_procedural_numbering()`: text containing `PRIMERO.-`, `SEGUNDO.-` as section markers — verify these are treated as separate sentence-like units (if NLTK Punkt splits them, it's acceptable — they're section boundaries, which are valid chunk boundaries)

    **Class 4: TestConfigurableSize (CHK-03)**
    - `test_default_target_size()`: `SmartChunker()` uses 524288 (512KB) when CHUNK_SIZE_TARGET not set
    - `test_explicit_target_size()`: `SmartChunker(target_size=500)` uses 500 regardless of env var
    - `test_env_var_overrides_default(monkeypatch)`: `monkeypatch.setenv("CHUNK_SIZE_TARGET", "1000")`, then `SmartChunker()` uses 1000. Clean up monkeypatch after (pytest fixture).
    - `test_empty_env_var_falls_back_to_default(monkeypatch)`: `monkeypatch.delenv("CHUNK_SIZE_TARGET", raising=False)`, then `SmartChunker()` uses 524288

    **Class 5: TestProvenance (CHK-04)**
    - `test_chunk_index_is_sequential()`: multi-chunk document → chunk indices are 0, 1, 2, ... without gaps
    - `test_offset_start_end_accurate()`: for each chunk, `text == original_text[offset_start:offset_end]`
    - `test_page_tracking()`: text with page_offsets=[0, 100, 200, 300]. Chunks that start in page 1 have page_start=1, chunks that span pages have correct page_start and page_end from _offset_to_page
    - `test_part_index_equals_chunk_index()`: verify that the sequential chunk_index field matches the expected part index for LLM pipeline consumption — no separate part_index field exists, chunk_index IS part_index

    **Class 6: TestIntegration**
    - `test_chunk_sample_civil_case()`: read `test_data/sample_civil_case.txt`, chunk with SmartChunker(target_size=1200). Assert all chunks have correct offsets, sentence-aware boundaries (no mid-sentence split verified by checking that each chunk's text equals `original_text[offset_start:offset_end]`), and approximately balanced sizes
    - `test_chunk_sample_criminal_case()`: same pattern for sample_criminal_case.txt
    - `test_chunk_sample_multi_page()`: read multi_page_document.txt, verify page tracking works for multi-page documents
