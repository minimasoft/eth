<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| nltk.org → Docker build | NLTK punkt_tab model is downloaded from nltk.org at image build time |
| docker-compose env vars → container | CHUNK_SIZE_TARGET value flows from host env or default into containers |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-34-01 | Tampering | docker-compose.yml CHUNK_SIZE_TARGET | accept | Environment variable is a configuration parameter, not a secret. Tampering with it changes chunk size but does not bypass security controls. Acceptable risk for a single-user research tool. |
| T-34-02 | Spoofing | nltk.org — model download source | mitigate | Dockerfile downloads from NLTK's official data server (nltk.org). The nltk library verifies model checksums internally. Running at build time (not runtime) reduces attack surface. |
| T-34-SC | Tampering | pip install nltk | mitigate | nltk is a well-established package (~20 years, PyPI). Package Legitimacy Audit in 34-RESEARCH.md verified against nltk.org official docs. Use `uv add` with PyPI index (configured in pyproject.toml `[[tool.uv.index]]`). |
</threat_model>
