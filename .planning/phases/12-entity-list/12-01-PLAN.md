## Objective

Add a paginated entity list endpoint (`GET /entities`) and frontend table UI in the Entities tab, following the Phase 11 Document List pattern.

## Context

The Entities tab currently shows a placeholder card. Users need to browse, search, and paginate through canonical entities. The pattern is already established by Phase 11 (GET /documents endpoint + document table UI).

See:
- `12-CONTEXT.md` — domain boundary, decisions, code context
- `12-UI-SPEC.md` — copywriting contract, design tokens

## Tasks

### Task 1: Pydantic models for entity list

**Files:** `src/eth_pipeline/api.py`

Add `EntityListItem` and `EntityListResponse` models after `DocumentListResponse` (~line 158).

### Task 2: `GET /entities` endpoint

**Files:** `src/eth_pipeline/api.py`

Add `list_entities` endpoint after `list_documents` (~line 906). Follow Phase 11 pattern:
- Query `canonical_entity` table with SurrealDB
- LIKE on `name` for search, exact match on `entity_type` for filter
- Exclude entities with `superseded_by IS NONE`
- Count total matching entities
- Paginated results with LIMIT/START
- For each entity, count references via `SELECT count() ... FROM reference WHERE canonical_entity = $id`
- Add `/entities` to the root endpoint docs
- 503 DB unavailable, 502 query failure

### Task 3: Entities tab frontend UI

**Files:** `src/eth_pipeline/static/index.html`

Replace placeholder card in `#tab-entities` with:
- Heading "Entities"
- Search input (300ms debounce on name) + type filter dropdown (All, place, person, object)
- HTML table: Name, Type, References
- Pagination controls ("Page X of Y" + Previous/Next)
- Loading state, empty state ("No entities found")
- Error handling via banner

Entity type displayed as capitalized plain text label (not colored badge).
