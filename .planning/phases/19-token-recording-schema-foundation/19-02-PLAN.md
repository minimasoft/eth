# Plan 19-02: OpenRouterProvider Usage Capture + Activity Wiring + Nullify Integration

**Phase:** 19 — Token Recording & Schema (Foundation)
**Type:** backend
**Dependencies:** Plan 19-01 (llm_usage table + module must exist)
**Status:** Pending

## Goal

Modify `OpenRouterProvider` to capture usage data from the raw API response, wire `record_llm_usage()` calls in all 3 LLM-calling activities, and add `llm_usage` cleanup to the nullify-then-recreate cycles.

## Tasks

### Task 1: Modify OpenRouterProvider to capture usage

**File:** `src/eth_pipeline/llm.py`

**Changes:**
1. Add `import time` to imports
2. Modify `extract_events()` and `resolve_references()` to return `(parsed_json: dict, usage: dict | None)` tuple
3. In each method:
   - Record `start = time.monotonic()` before HTTP call
   - After `data = response.json()`, compute `duration_ms = int((time.monotonic() - start) * 1000)`
   - Extract `usage_raw: dict | None = data.get("usage")`
   - Build usage dict with: prompt_tokens, completion_tokens, total_tokens, cached_tokens, cache_write_tokens, reasoning_tokens, model, cost, duration_ms
   - Return `(self._parse_choice(data), usage)` where usage is enriched dict or None

4. Modify top-level convenience functions `extract_events()` and `resolve_references()` (lines ~629-710) to return `tuple[dict, dict | None]`

**Verification:** Unit test verifies that when mock response has usage data, the method returns (parsed, usage_dict). When usage is absent, returns (parsed, None).

### Task 2: Wire record_llm_usage() in extract_events_activity

**File:** `src/eth_pipeline/activities.py` (line ~197)

**Changes:**
1. Add import: `from eth_pipeline.llm_usage import record_llm_usage`
2. In the chunk loop, after `chunk_result, usage = await provider.extract_events(chunk, prior_events=prior)`:
   - If usage is not None, call:
     ```python
     await record_llm_usage(
         db_params=params,
         document_id=document_id,
         step_name="extract_events",
         chunk_index=i,
         model=model,
         prompt_tokens=usage["prompt_tokens"],
         completion_tokens=usage["completion_tokens"],
         total_tokens=usage["total_tokens"],
         duration_ms=usage["duration_ms"],
         cached_tokens=usage.get("cached_tokens"),
         cache_write_tokens=usage.get("cache_write_tokens"),
         reasoning_tokens=usage.get("reasoning_tokens"),
         cost=usage.get("cost"),
         cost_source="openrouter" if usage.get("cost") is not None else None,
     )
     ```

**Verification:** Unit test with mock provider and mock db verifies record_llm_usage is called with correct params.

## Success Criteria

1. Every OpenRouter response produces a record in `llm_usage` table with non-zero token counts
2. Replaying the same document produces identical records (UPSERT idempotency)
3. Clearing document events deletes associated llm_usage records
4. Deleting a document cascades to its llm_usage records
5. Token recording failure does not crash the activity (warning-only)
