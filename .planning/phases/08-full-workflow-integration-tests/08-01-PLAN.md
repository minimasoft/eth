  <name>Task 2: Refactor DocumentProcessingWorkflow with conditional blob/text branch</name>

  <files>
    src/eth_pipeline/workflows.py
  </files>

  <action>
    Rewrite the `DocumentProcessingWorkflow` class in `workflows.py` to add conditional branching. The new design:

    1. **Signatures change**: `run(self, document_id: str)` — remove the `text` parameter entirely. The workflow now discovers the document type at runtime via the helper activities.

    2. **Imports**: Add the new activities to the `with workflow.unsafe.imports_passed_through()` block:
       - `get_document_metadata_activity`
       - `get_document_text_activity`
       - `extract_text_activity`
       - `chunk_document_activity`
       - `store_chunks_activity`

    3. **Workflow logic** (inside `run`):

       ```python
       try:
           # Step 1: Mark document as processing
           await workflow.execute_activity(
               update_document_status_activity,
               args=[document_id, "processing"],
               start_to_close_timeout=timedelta(seconds=10),
           )

           # Step 2: Get document metadata to determine path
           metadata = await workflow.execute_activity(
               get_document_metadata_activity,
               args=[document_id],
               start_to_close_timeout=timedelta(seconds=10),
           )
           if "error" in metadata:
               raise RuntimeError(metadata["error"])

           # Step 3: Conditional branch
           has_text_content = metadata.get("has_text_content", False)
           blob_format = metadata.get("blob_format")

           if blob_format is not None:
               # ---- BLOB PATH (Binary PDF) ----
               # Mark as extracting blob
               await workflow.execute_activity(
                   update_document_status_activity,
                   args=[document_id, "extracting_blob"],
                   start_to_close_timeout=timedelta(seconds=10),
               )

               # Extract text from blob
               extraction_result = await workflow.execute_activity(
                   extract_text_activity,
                   args=[document_id],
                   start_to_close_timeout=timedelta(seconds=120),
               )
               if "error" in extraction_result:
                   raise RuntimeError(extraction_result["error"])

               # Chunk document
               chunk_result = await workflow.execute_activity(
                   chunk_document_activity,
                   args=[document_id, extraction_result],
                   start_to_close_timeout=timedelta(seconds=30),
               )
               if "error" in chunk_result:
                   raise RuntimeError(chunk_result["error"])

               # Store chunks
               await workflow.execute_activity(
                   store_chunks_activity,
                   args=[document_id, chunk_result],
                   start_to_close_timeout=timedelta(seconds=30),
               )

               # Get the full reconstructed text from the document
               text_data = await workflow.execute_activity(
                   get_document_text_activity,
                   args=[document_id],
                   start_to_close_timeout=timedelta(seconds=10),
               )
               text = text_data.get("text_content", "")
           else:
               # ---- TEXT PATH (Direct text) ----
               text = metadata.get("text_content", "")

           # Step 4: Extract events from full text (same for both paths)
           result = await workflow.execute_activity(
               extract_events_activity,
               text,
               start_to_close_timeout=timedelta(seconds=60),
               retry_policy=RetryPolicy(
                   maximum_attempts=3,
                   initial_interval=timedelta(seconds=5),
                   backoff_coefficient=2.0,
               ),
           )

           # Step 5: Store extraction results
           await workflow.execute_activity(
               store_extraction_results_activity,
               args=[document_id, result],
               start_to_close_timeout=timedelta(seconds=10),
           )

           # Step 6: Resolve verbatim references
           await workflow.execute_activity(
               resolve_entities_activity,
               args=[document_id, result],
               start_to_close_timeout=timedelta(seconds=30),
           )

           # Step 7: Return summary
           events = result.get("events", [])
           return {
               "document_id": document_id,
               "event_count": len(events),
               "status": "processed",
           }

       except Exception as exc:
           await workflow.execute_activity(
               update_document_status_activity,
               args=[document_id, "failed", str(exc)],
               start_to_close_timeout=timedelta(seconds=10),
           )
           raise
       ```

    4. **Chunk transparency**: The `text` variable passed to `extract_events_activity` at step 4 is the **full reconstructed text** from `document.text_content` — either fetched via `get_document_text_activity` (blob path, after extraction stored it) or read from the metadata (text path). The workflow never passes chunk data (text from individual `document_chunk` records) to `extract_events_activity`. This guarantees chunk transparency per SC-6.

    5. **Lazy migration**: Legacy base64 documents have `blob_format = null` and `text_content = null`. The conditional check `blob_format is not None` sends them through the text path, where `text_content` is empty. But wait — legacy base64 docs need extraction too! 

       **Important fix**: Change the branch condition. The correct split is:
       - **BLOB PATH**: `blob_format is not None` (new MinIO docs) **OR** `not has_text_content` (legacy docs needing extraction, including legacy base64 blobs)
       - **TEXT PATH**: `has_text_content is True` (text docs already populated)

       Updated condition:
       ```python
       if not has_text_content:
           # BLOB PATH — need to extract text regardless of format
           ...
       else:
           # TEXT PATH — text already available
           text = metadata.get("text_content", "")
       ```

       This handles all three cases correctly:
       - New MinIO blobs: `blob_format="minio"`, `text_content=null` → extraction path ✓
       - Legacy base64 blobs: `blob_format=null`, `text_content=null` → extraction path ✓ (extract_text_activity handles both via its internal check)
       - Text docs: `blob_format=null`, `text_content="..."` → text path ✓

       Also add a status update for the blob path:
       ```python
       if not has_text_content:
           await workflow.execute_activity(
               update_document_status_activity,
               args=[document_id, "extracting_blob"],
               ...
           )
       ```

    6. **Update `__all__`** — unchanged (still exports `DocumentProcessingWorkflow`).

    7. **Update docstrings** — rewrite the class docstring and `run` method docstring to document the two-path conditional branching, the intermediate status values, and chunk transparency.

    8. **Keep the `from __future__ import annotations`** and all existing imports.
  </action>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Tampering | DocumentProcessingWorkflow conditional branch | mitigate | `not has_text_content` condition checked via get_document_metadata_activity — both text and blob paths converge on same extract_events_activity call, ensuring consistent event extraction regardless of source |
| T-08-02 | Repudiation | document_chunk DELETE cascade | mitigate | DELETE order is: chunks → references → events → document reset. If cascade breaks mid-sequence, no orphaned records guaranteed (delete-then-recreate idempotency pattern) |
| T-08-03 | Info Disclosure | Chunk transparency | accept | extract_events_activity receives full `document.text_content`, never chunk records (architectural guarantee). Chunk data is internal — LLM never sees individual chunks. Per Out of Scope in REQUIREMENTS.md |
| T-08-04 | Denial of Service | Blob path in workflow | mitigate | extract_text_activity timeouts (120s), chunk_document_activity timeout (30s). pdf extraction quality gate prevents DoS via corrupt PDFs. 50MB upload limit on API end |
| T-08-05 | Elevation of Privilege | SurrealDB record links | accept | All record links are internal (document→document_chunk, event→document). No untrusted input shapes record link values |
| T-08-06 | Tampering | Legacy base64 doc extraction | mitigate | Legacy docs with blob_format=null and text_content=null correctly route through extraction path via `not has_text_content` branch. The extract_text_activity handles both minio and base64 sources internally |
| T-08-07 | Spoofing | Workflow trigger from API | accept | No auth layer — any client can trigger workflows. Documented degraded-mode pattern. Mitigation deferred to v3.0 auth |
</threat_model>
