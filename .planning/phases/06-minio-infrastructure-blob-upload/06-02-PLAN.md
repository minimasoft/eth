  <action>
    Add a new `POST /documents/upload` endpoint to `src/eth_pipeline/api.py`, following the patterns established by the existing `POST /documents` endpoint.

    **Pydantic model** — Add after `DocumentCreated`:
    ```python
    class DocumentUploadCreated(BaseModel):
        document_id: str
        status: str = "pending"
    ```

    **Endpoint** — Add after the existing `create_document` function:

    ```python
    @app.post("/documents/upload", response_model=DocumentUploadCreated, status_code=201)
    async def upload_document(file: UploadFile = File(...)):
    ```

    Implementation:
    1. **Validate file** — Check `file.filename` is not empty (400 if missing). Accept any MIME type (extraction phase handles format-specific logic).
    2. **Generate doc_id** — `str(uuid.uuid4().hex)` (same pattern as `create_document`).
    3. **Blob path** — Determine extension from `file.filename`: if filename has an extension (e.g., `.pdf`, `.txt`), use it; default to `.bin`. Path: `f"doc/{doc_id}{ext}"`.
    4. **Read file** — `content = await file.read()`. Guard against files > 50 MB (HTTP 413).
    5. **Storage backend degraded mode** — Connect to MinIO via `get_storage_async()` (import from `eth_pipeline.storage`). If MinIO is unavailable (catches `ConnectionError`), fall back to storing the blob as base64-encoded `original_blob` in SurrealDB (same as the text endpoint). Log a warning about degraded mode.
    6. **Store in MinIO** (when available):
       - `client.put_object(bucket, blob_path, io.BytesIO(content), len(content), content_type=file.content_type or "application/octet-stream")`
       - Set `blob_format = "minio"`, `blob_path = blob_path`, `original_blob = None`
    7. **Store in SurrealDB** — Same create pattern as `create_document`:
       ```python
       await db.create(f"document:{doc_id}", {
           "text_content": None,
           "original_blob": None if minio_available else base64_blob,
           "blob_format": "minio" if minio_available else None,
           "blob_path": blob_path if minio_available else None,
           "filename": file.filename or f"unnamed_{doc_id}",
           "mime_type": file.content_type or "application/octet-stream",
           "status": "pending",
           "error_message": None,
       })
       ```
    8. **Trigger Temporal** — Same best-effort pattern as `create_document`:
       - If temporal available: `await temporal.start_workflow(DocumentProcessingWorkflow.run, id=f"doc-{doc_id}", task_queue="event-extraction", args=[doc_id, ""], id_conflict_policy=1)`
       - Pass empty string for text (Phase 7 will add text extraction; for now the workflow receives empty text and returns no events gracefully)
    9. **Return** — `DocumentUploadCreated(document_id=doc_id, status="pending")`
    10. **Import additions** needed:
        - From `fastapi`: `UploadFile`, `File`
        - From `eth_pipeline.storage`: `get_storage_async`
        - `io` (for `io.BytesIO`)
        - `os` (already imported in api.py)

    **Error handling** (mirror existing endpoints):
    - SurrealDB unavailable → HTTP 503
    - File too large (> 50 MB) → HTTP 413
    - MinIO unavailable during store → fall back to degraded mode (base64), don't fail the request
    - SurrealDB store fails → HTTP 502

    **Update root endpoint** — Add `"/documents/upload"` to the `endpoints` dict in `root()` so it shows in the API info.

    **Important:** Do NOT modify the existing `POST /documents` endpoint — text-based submissions must remain fully backward compatible (satisfies Phase 8 lazy migration requirement).
