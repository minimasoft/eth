**Test approach:** Since there are no Python API test files in this codebase (only DB-level tests), test by executing the same SQL queries the route handlers use against the seeded test fixtures, then asserting on query results. This validates the SQL logic without requiring a running FastAPI server.

**Class 1: `TestEventListV2`**

**test_pagination_envelope** — `@pytest.mark.asyncio`, parametrize fixture: `db_connection, v7_test_event`
1. Query `SELECT COUNT(*) AS total FROM event_v2` to verify at least 1 event exists (from fixture)
2. Execute COUNT query with `WHERE TRUE` (matching list_events_v2 base query): `SELECT COUNT(*) AS total FROM event_v2 ev WHERE TRUE`
3. Assert `total >= 1`
4. Execute data query: `SELECT ev.* FROM event_v2 ev WHERE TRUE ORDER BY ev.time_start DESC LIMIT 20 OFFSET 0`
5. Assert result has rows
6. Verify each row has expected columns: `id`, `title`, `description`, `time_start`, `time_end`, `time_precision`, `extraction_confidence`, `document_id`, `created_at`, `updated_at`
7. Compute pages: `pages = max(1, (total + 20 - 1) // 20)` 
8. Assert `pages >= 1`

**test_filter_by_document** — `@pytest.mark.asyncio`, fixtures: `db_connection, v7_test_event`
1. Extract `doc_id = v7_test_event["document_id"]`
2. Execute: `SELECT COUNT(*) AS total FROM event_v2 ev WHERE ev.document_id = $1` with `doc_id`
3. Assert `total >= 1` (at least the seeded event matches)
4. Execute: `SELECT ev.* FROM event_v2 ev WHERE ev.document_id = $1 ORDER BY ev.time_start DESC LIMIT 20 OFFSET 0`
5. Assert all returned rows have `document_id == doc_id`
6. Execute negative filter: `SELECT COUNT(*) AS total FROM event_v2 ev WHERE ev.document_id = 'nonexistent-id'`
7. Assert `total == 0`

**test_search_by_title** — `@pytest.mark.asyncio`, fixtures: `db_connection, v7_test_event`
1. Execute: `SELECT COUNT(*) AS total FROM event_v2 ev WHERE ev.title ILIKE $1` with `"%Reunión%"`
2. Assert `total >= 1` (matches "Reunión de prueba" from fixture)
3. Execute: `SELECT COUNT(*) AS total FROM event_v2 ev WHERE ev.title ILIKE $1` with `"%ZZZZNOTEXIST%"`
4. Assert `total == 0`

**test_sort_by_time** — `@pytest.mark.asyncio`, fixtures: `db_connection, v7_test_event`
1. Seed a SECOND event with a different time_start for sort validation:
   ```
   await db_connection.execute(
       "INSERT INTO event_v2 (id, document_id, title, description, time_start, time_end, extraction_confidence) "
       "VALUES ($1, $2, $3, $4, $5, $6, $7) ON CONFLICT (id) DO NOTHING",
       "test-events-v7-ev-002", v7_test_event["document_id"],
       "Evento anterior", "Evento más antiguo para sort test",
       datetime(2023, 1, 1, tzinfo=timezone.utc),
       datetime(2023, 1, 1, 12, 0, 0, tzinfo=timezone.utc),
       0.85,
   )
   ```
2. Execute with `ORDER BY ev.time_start DESC LIMIT $1 OFFSET $2` (per_page=20, offset=0)
3. Assert first row's title is "Reunión de prueba" (2024-06-01 > 2023-01-01 → DESC means newer first)
4. Execute with `ORDER BY ev.time_start ASC LIMIT $1 OFFSET $2`
5. Assert first row's title is "Evento anterior" (2023-01-01 < 2024-06-01 → ASC means older first)
6. Clean up: `DELETE FROM event_v2 WHERE id = 'test-events-v7-ev-002'`

from __future__ import annotations

import logging

**Class: `TestChunkText`**

**test_chunk_text_with_offsets** — `@pytest.mark.asyncio`, fixtures: `db_connection, v7_test_chunk`
1. Extract `doc_id = v7_test_chunk["document_id"]` and `chunk_idx = v7_test_chunk["chunk_index"]`
2. Execute the same SQL as `get_chunk_text`:
   `SELECT chunk_index, text, offset_start, offset_end FROM document_chunk WHERE document = $1 AND chunk_index = $2`
   with `doc_id, chunk_idx`
3. Assert `chunk_row` is not None
4. Assert `chunk_row["chunk_index"] == chunk_idx` (0)
5. Assert `chunk_row["text"] == "Texto de prueba para el chunk 0. Contiene información relevante."`
6. Assert `chunk_row["offset_start"] == 0`
7. Assert `chunk_row["offset_end"] == 61` (length of the text)
8. Compute chunk-relative offsets:
   `chunk_text = chunk_row["text"] or ""`
   `chunk_offset_start = 0`
   `chunk_offset_end = len(chunk_text)`
9. Assert `chunk_offset_start == 0`
10. Assert `chunk_offset_end == 61`

**test_chunk_404** — `@pytest.mark.asyncio`, fixtures: `db_connection`
1. Query: `SELECT chunk_index, text, offset_start, offset_end FROM document_chunk WHERE document = $1 AND chunk_index = $2`
   with `document_id="nonexistent-doc-id"`, `part_index=0`
2. Assert `chunk_row` is None (→ 404 in endpoint)
3. Query a valid document_id with out-of-range chunk_index:
   with `document_id="test-events-v7-doc-001"`, `part_index=999`
4. Assert `chunk_row` is None

**test_chunk_empty_text** — `@pytest.mark.asyncio`, fixtures: `db_connection, v7_test_document`
1. INSERT a chunk with NULL text column:
   ```
   await db_connection.execute(
       "INSERT INTO document_chunk (id, chunk_index, text, page_start, page_end, offset_start, offset_end, document) "
       "VALUES ($1, $2, $3, $4, $5, $6, $7, $8) ON CONFLICT (id) DO NOTHING",
       "test-events-v7-chk-empty", 1, None, 1, 1, 62, 62, v7_test_document,
   )
   ```
2. Query: `SELECT chunk_index, text, offset_start, offset_end FROM document_chunk WHERE document = $1 AND chunk_index = $2`
   with `v7_test_document, 1`
3. Assert `chunk_row["text"]` is None
4. Apply `or ""` fallback: `chunk_text = chunk_row["text"] or ""`
5. Assert `chunk_text == ""`
6. Assert `len(chunk_text) == 0`
7. Cleanup: `DELETE FROM document_chunk WHERE id = 'test-events-v7-chk-empty'`

Do NOT include fenced code blocks. Follow the same test patterns as Task 1. Use try/finally for cleanup of inserted rows.
