```
@router.get("/documents/{document_id}/chunks/{part_index}", response_model=ChunkTextResponse)
async def get_chunk_text(
    document_id: str,
    part_index: int,
) -> ChunkTextResponse:
    """Get chunk text content with absolute and chunk-relative offset info."""
```

**Function body** (follow get_document pattern lines 350-368):

1. `try:` → `async with get_db() as conn:`
   - `chunk_row = await conn.fetchrow(...)` with SQL:
     `"SELECT chunk_index, text, offset_start, offset_end FROM document_chunk WHERE document = $1 AND chunk_index = $2"`
     params: `document_id, part_index`

2. `except Exception as exc:` → `logger.error(...)` + `raise HTTPException(status_code=502, detail="Failed to query database.") from exc`

3. `if not chunk_row:` → `logger.warning(...)` + `raise HTTPException(status_code=404, detail=f"Chunk not found: document {document_id}, part {part_index}")`

4. Compute chunk-relative offsets:
   ```
   chunk_text = chunk_row["text"] or ""
   chunk_offset_start = 0
   chunk_offset_end = len(chunk_text)
   ```

5. Log: `logger.info("Chunk text for %s part %d — %d chars", document_id, part_index, len(chunk_text))`

6. Return `ChunkTextResponse(
       document_id=document_id,
       part_index=part_index,
       text=chunk_text,
       offset_start=chunk_row["offset_start"],
       offset_end=chunk_row["offset_end"],
       chunk_offset_start=chunk_offset_start,
       chunk_offset_end=chunk_offset_end,
   )`

**Key details:**
- `chunk_offset_start` is ALWAYS 0 (start of chunk text)
- `chunk_offset_end` is ALWAYS `len(text)` (exclusive end)
- `offset_start`/`offset_end` come from the `document_chunk` table (document-absolute character offsets)
- Parameter `part_index` maps to `chunk_index` column in document_chunk
- 404 when no matching row (document doesn't exist OR chunk_index out of range)
- 502 when DB connection fails

Do NOT include fenced code blocks. Follow existing error handling and logging patterns exactly.
