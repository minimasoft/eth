  <action>
    Create `src/eth_pipeline/offsets.py` implementing a pure function
    `compute_reference_offsets()`.

    **Function signature:**

    ```
    def compute_reference_offsets(
        span_start: int,
        span_end: int,
        chunks: list[dict],
        is_plain_text: bool,
    ) -> dict:
    ```

    **Parameters:**
    - `span_start`, `span_end`: The existing document-level character offsets on
      the reference record. These are 0-based, from the LLM extraction against
      the full document text.
    - `chunks`: List of document_chunk dicts sorted by `chunk_index` ascending.
      Each dict has keys: `chunk_index`, `offset_start`, `offset_end`,
      `page_start`, `page_end`. Guaranteed non-empty (activity checks for this).
    - `is_plain_text`: `True` if document has no page structure (mime_type
      starting with "text/").

    **Return dict:** One of:
    - `{"page_number": int, "page_offset_start": int, "page_offset_end": int}`
    - `{"page_number": None, "page_offset_start": None, "page_offset_end": None}`
      when is_plain_text=True or span is out of range.

    **Algorithm (per D-06, D-07):**

    1. **Reconstruct page_offsets array from chunks** (per D-07):
       Iterate through sorted chunks in order. For each unique `page_start`
       value in order, record the corresponding `offset_start`. Then set the
       last page boundary as the last chunk's `offset_end`. This produces
       `page_offsets = [p1_start, p2_start, ..., document_end]`.

       Simplified approach (handles common case of single-page chunks):
       ```
       page_offsets = []
       seen_pages = set()
       for chunk in chunks:
           if chunk["page_start"] not in seen_pages:
               seen_pages.add(chunk["page_start"])
               page_offsets.append(chunk["offset_start"])
       if not page_offsets or page_offsets[0] != 0:
           page_offsets.insert(0, 0)
       page_offsets.append(chunks[-1]["offset_end"])
       page_offsets.sort()
       ```

    2. **Detect out-of-range spans** (per D-03):
       - If `span_start < 0` or `span_end > chunks[-1]["offset_end"]`, return
         null dict (the call site in activities.py handles the warning log).
       - If `span_start >= span_end`, return null dict.

    3. **Compute page_number** (per D-06):
       ```
       for i in range(len(page_offsets) - 1):
           if page_offsets[i] <= span_start < page_offsets[i + 1]:
               page_number = i + 1
               break
       else:
           page_number = len(page_offsets) - 1  # fallback: last page
       ```

    4. **Compute page-relative offsets**:
       ```
       page_offset_start = span_start - page_offsets[page_number - 1]
       page_offset_end = span_end - page_offsets[page_number - 1]
       ```

    5. **If is_plain_text**, immediately return null dict (per D-02).

    **Also export** a helper `reconstruct_page_offsets(chunks: list[dict]) -> list[int]`
    that implements step 1 above, so it can be unit-tested independently.

    **Module-level docstring:** explain that this module provides deterministic
    page/offset computation for reference records, using document_chunk table
    metadata as the source of truth. No LLM involvement.

    **No imports from activities.py or any Temporal module.** This is a pure
    data-transformation module. Standard library only + typing imports.
  </action>

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-14-02 | Info Disclosure | negative span_start | mitigate | compute_reference_offsets checks span_start >= 0 — returns nulls for negative values |
| T-14-03 | Denial of Service | out-of-range page_number | mitigate | span beyond document length returns null + warning, does not crash |
| T-14-04 | Tampering | null/None chunk fields | mitigate | reconstruct_page_offsets uses .get() with defaults (0 for offsets, 1 for page pages); missing keys handled gracefully |
| T-14-SC | Tampering | pip installs (pytest) | accept | pytest already present in virtual environment; no new packages needed |
