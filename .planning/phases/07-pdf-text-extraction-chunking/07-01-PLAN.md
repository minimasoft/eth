    ```python
    @dataclass
    class ExtractionResult:
        """Result from a content extractor."""
        text: str
        """Full extracted text."""
        page_count: int
        """Total number of pages in the source document."""
        page_offsets: list[int]
        """Cumulative character offset for the start of each page.
        Length = page_count + 1, where offset[0]=0 and offset[page_count]=len(text).
        e.g. [0, 523, 1047, 1570] means page 0 is text[0:523], page 1 is text[523:1047], etc.
        """
        metadata: dict | None = None
        """Optional extractor-specific metadata (PDF version, title, etc.)."""
    ```

    **2. ContentExtractor Protocol (EXTR-01)**
    ```python
    class ExtractorQualityError(Exception):
        """Raised when document quality prevents extraction (empty, scanned-only, corrupt)."""
        def __init__(self, message: str, reason: str = "quality_gate"):
            self.reason = reason
            super().__init__(message)

    class ContentExtractor(Protocol):
        """Protocol for pluggable document content extractors.
        
        Implementations extract text with page-level offset tracking
        from a binary blob. The protocol is format-agnostic — implement
        for PDF, DOCX, images, etc.
        """
        def extract(self, content: bytes, filename: str = "") -> ExtractionResult:
            """Extract text from binary content.
            
            Args:
                content: Raw binary content of the document.
                filename: Original filename (may inform format detection).
            
            Returns:
                ExtractionResult with full text + page offset metadata.
            
            Raises:
                ExtractorQualityError: Document is empty, scanned-only, or corrupt.
            """
            ...
    ```

    **3. _page_count_for_text helper**
    A helper to estimate page count from text alone (used by pypdf fallback which doesn't provide page info for scanned PDFs):
    ```python
    def _estimate_page_count(text: str, avg_chars_per_page: int = 3000) -> int:
        return max(1, (len(text) + avg_chars_per_page - 1) // avg_chars_per_page)
    ```

    **4. PdfExtractor (EXTR-02, primary: pypdfium2)**
    Primary extractor using pypdfium2 (BSD-3-Clause license, no AGPL concerns):

    - Read `USE_PYPDF` env var (string, default empty). If `USE_PYPDF` is truthy ("true"/"1"/"yes"), delegate to the fallback `_extract_with_pypdf()`.
    - Otherwise, attempt pypdfium2:
      - `import pypdfium2 as pdfium` (lazy import — catch ImportError and fall back to pypdf)
      - Open: `pdfium.PdfDocument(content)` — accepts bytes directly
      - Iterate pages: `for i in range(len(pdf)): page = pdf[i]`
      - Extract text: `text = page.get_text_bounded()` (returns str)
      - Build `page_offsets`: start at 0, for each page append `prev_offset + len(page_text)`
      - Total text: `"\n\n".join(page_texts)` with `\f` (form feed) between pages as fallback separator
      - Accumulate page_count from `len(pdf)`
    
    **5. PdfExtractor quality gate (EXTR-04)**
    After extraction, check:
    - If `len(text.strip()) == 0` → raise `ExtractorQualityError("The PDF appears to be empty or contains no extractable text (it may be a scanned document with no text layer). Try OCR or a document with embedded text.", reason="empty_or_scanned")`
    - If `page_count == 0` → raise `ExtractorQualityError("The PDF has zero pages.", reason="empty")`
    - If `len(text.strip()) < 50` and `page_count > 1` → raise `ExtractorQualityError("The PDF has {page_count} pages but almost no extractable text ({len} chars). It may be a scanned document. Try a document with a text layer or use an OCR pipeline.", reason="likely_scanned")`

    **6. PdfExtractor pypdf fallback (EXTR-03)**
    `_extract_with_pypdf()` method:
    - `from pypdf import PdfReader`
    - `reader = PdfReader(BytesIO(content))`
    - Iterate `reader.pages`: `page.extract_text()`
    - Build same `page_offsets` structure as pypdfium2 path
    - Apply same quality gate checks
    - Note: pypdf's `extract_text()` is less accurate than pypdfium2's — this is the documented trade-off for the AGPL mitigation path.

    **7. Registry for future format extension (EXTR-01)**
    A simple dict-based registry at module level:
    ```python
    _extractors: dict[str, type[ContentExtractor]] = {}

    def register_extractor(format: str, extractor_cls: type[ContentExtractor]) -> None:
        _extractors[format] = extractor_cls

    def get_extractor(format: str) -> type[ContentExtractor] | None:
        return _extractors.get(format)

    # Auto-register PDF
    register_extractor("pdf", PdfExtractor)
    ```

    **8. Module-level convenience function**
    ```python
    def extract_text(content: bytes, filename: str = "") -> ExtractionResult:
        """Auto-detect format from filename and extract text."""
        ext = Path(filename).suffix.lower() if filename else ""
        format_map = {".pdf": "pdf"}
        fmt = format_map.get(ext, ext.lstrip(".") if ext else "pdf")
        cls = get_extractor(fmt) or PdfExtractor  # default to PDF
        return cls().extract(content, filename=filename)
    ```

    Create `src/eth_pipeline/chunker.py` that provides page-provenance-tracked text chunking:

    **1. Data model**
    ```python
    @dataclass
    class DocumentChunk:
        """A single chunk of a document with page-level provenance."""
        chunk_index: int
        """Zero-based index of this chunk within the document."""
        text: str
        """The chunk's text content."""
        page_start: int
        """Page number (1-based) where this chunk's text begins."""
        page_end: int
        """Page number (1-based, inclusive) where this chunk's text ends."""
        offset_start: int
        """Character offset (0-based) where this chunk begins in the full document text."""
        offset_end: int
        """Character offset (exclusive) where this chunk ends in the full document text."""

    @dataclass
    class ChunkResult:
        """Result from DocumentChunker."""
        chunks: list[DocumentChunk]
        """The produced chunks."""
        chunk_size_target: int
        """Target chunk size used."""
        total_text_length: int
        """Length of the full document text."""
    ```

    **2. DocumentChunker (CHNK-01, CHNK-02, CHNK-03)**

    Use `langchain_text_splitters.RecursiveCharacterTextSplitter` internally:

    ```python
    class DocumentChunker:
        """Split document text into chunks with page-provenance tracking.
        
        Uses RecursiveCharacterTextSplitter with paragraph/punctuation-aware
        boundaries. Tracks which page range each chunk covers by mapping
        character offsets to page numbers via the page_offsets array from
        ExtractionResult.
        """
        
        DEFAULT_CHUNK_SIZE: ClassVar[int] = 128_000  # ~128k chars
        
        def __init__(
            self,
            chunk_size: int = DEFAULT_CHUNK_SIZE,
            chunk_overlap: int = 0,
        ):
            self.chunk_size = chunk_size
            self.chunk_overlap = chunk_overlap
        
        def chunk(
            self,
            text: str,
            page_offsets: list[int],
        ) -> ChunkResult:
            ...
    ```

    Implementation of `chunk()`:
    1. Build `RecursiveCharacterTextSplitter`:
       - `chunk_size = self.chunk_size`
       - `chunk_overlap = self.chunk_overlap` (0 for Phase 7 — no overlap needed since chunks are internal)
       - `separators = ["\n\n", "\n", ".", "!", "?", ",", " ", ""]` — paragraph → sentence → character
       - `length_function = len`
    2. Call `splitter.split_text(text)` — returns `list[str]`
    3. For each chunk text, determine page range:
       - Compute `offset_start` as the position of this chunk in the original text:
         - Walk through the text tracking cumulative position (since RecursiveCharacterTextSplitter returns the texts, not their positions)
         - Use `text.find(chunk_text, last_position)` to locate each chunk (handles exact substrings)
         - Or more robustly: iterate through text tracking character-by-character to find each chunk boundary
       - Map `offset_start` and `offset_end` to pages using `page_offsets`:
         - `page_offsets` is list of cumulative offsets: `[0, p1_start, p2_start, ..., total_length]`
         - `page_start = 1 + max(i for i, off in enumerate(page_offsets[:-1]) if off <= offset_start)`
         - `page_end = 1 + max(i for i, off in enumerate(page_offsets[:-1]) if off < offset_end)`
         - Or simpler: binary search / loop through page_offsets to find which page range covers `[offset_start, offset_end)`
    4. Build `DocumentChunk` for each chunk
    5. Validate: concatenating all chunk texts in order must equal the original `text` (assert in dev)

    **Edge cases:**
    - `text` shorter than `chunk_size`: single chunk, page_start=1, page_end=page_count
    - Empty text: return single empty chunk with page_start=1, page_end=1, offset_start=0, offset_end=0
    - Chunk boundary falls mid-page: page_start and page_end correctly represent the partial-page span
    - page_offsets has wrong length: raise ValueError with descriptive message

    **3. Convenience function**
    ```python
    def chunk_document(
        text: str,
        page_offsets: list[int],
        chunk_size: int = DocumentChunker.DEFAULT_CHUNK_SIZE,
    ) -> ChunkResult:
        return DocumentChunker(chunk_size=chunk_size).chunk(text, page_offsets)
    ```
