    ```surql
    -- ==========================================================================
    -- Table: document_chunk
    -- ==========================================================================
    -- Stores text chunks extracted from a document's content, with page-level
    -- provenance. Each chunk records its position in the chunk sequence, the
    -- page range it covers (1-based), and the character offset range in the
    -- full document text. Chunks are internal — the LLM extraction pipeline
    -- always receives the full reconstructed text from document.text_content.
    -- ==========================================================================
    
    DEFINE TABLE document_chunk SCHEMAFULL
        COMMENT 'Text chunk from a document with page-level provenance (internal — LLM never sees individual chunks)';
    
    DEFINE FIELD chunk_index ON TABLE document_chunk TYPE int
        ASSERT $value >= 0
        COMMENT 'Zero-based index of this chunk in the document chunk sequence';
    
    DEFINE FIELD text ON TABLE document_chunk TYPE string
        COMMENT 'The chunk text content';
    
    DEFINE FIELD page_start ON TABLE document_chunk TYPE int
        ASSERT $value >= 1
        COMMENT 'Page number (1-based) where this chunk begins in the source document';
    
    DEFINE FIELD page_end ON TABLE document_chunk TYPE int
        ASSERT $value >= 1
        COMMENT 'Page number (1-based, inclusive) where this chunk ends in the source document';
    
    DEFINE FIELD offset_start ON TABLE document_chunk TYPE int
        ASSERT $value >= 0
        COMMENT 'Character offset (0-based) where this chunk starts in the full document text_content';
    
    DEFINE FIELD offset_end ON TABLE document_chunk TYPE int
        ASSERT $value >= 0
        COMMENT 'Character offset (exclusive) where this chunk ends in the full document text_content';
    
    DEFINE FIELD document ON TABLE document_chunk TYPE record<document>
        COMMENT 'Link to the source document that this chunk belongs to';
    
    DEFINE FIELD created_at ON TABLE document_chunk TYPE datetime
        DEFAULT time::now() READONLY
        COMMENT 'Timestamp when the chunk record was created (immutable after insertion)';
    ```

    Note: Do NOT add `updated_at` — chunks are deleted and recreated (idempotent pattern), not updated.

    Insert the table definition in the logical position: after the document table's field block (line 68) and before the event table block (line 70). The exact insertion point is between the `updated_at` field definition for the `document` table and the `-- ==========================================================================` separator for the `event` table.

    **Activity 1: `extract_text_activity` (EXTR-05)**

    ```python
    @activity.defn
    async def extract_text_activity(document_id: str) -> dict:
        """Extract text from a blob-stored document using PdfExtractor.
        
        Reads the document record from SurrealDB to get blob_format and
        blob_path. If blob_format == "minio", fetches the blob from MinIO
        and runs PdfExtractor. If blob_format is None (legacy base64),
        decodes original_blob from the document record and runs PdfExtractor.
        
        Updates document status to "extracting_text" on success.
        Sets document.text_content with the extracted text.
        Updates document.status to "failed" with error_message on quality gate failure.
        
        Returns:
            dict with document_id, text_length, page_count, page_offsets on success
            dict with error, document_id, error_message on failure
        """
    ```

    Implementation:
    1. Connect to SurrealDB via `get_db(**params)` (reuse `_db_params()`)
    2. Query the document record:
       ```python
       raw = await db.query(
           f"SELECT * FROM {doc_ref}",
       )
       ```
    3. If no record: return `{"error": "Document not found", "document_id": document_id}`
    4. Extract `blob_format`, `blob_path`, `original_blob`, `filename`, `mime_type`
    5. Get the binary content:
       - If `blob_format == "minio"`: use `get_storage()` (sync context manager — wrap in `asyncio.to_thread()`) to call `client.get_object(bucket, blob_path)`, read data via `.read()`
       - If `blob_format` is None (legacy): `content = base64.b64decode(original_blob.encode("ascii"))`
    6. Run PdfExtractor:
       ```python
       extractor = PdfExtractor()
       try:
           result = extractor.extract(content, filename=filename)
       except ExtractorQualityError as exc:
           await db.query(f"UPDATE {doc_ref} SET status = 'failed', error_message = $msg, updated_at = time::now()", {"msg": str(exc)})
           return {"error": str(exc), "document_id": document_id, "reason": exc.reason}
       ```
    7. Update document in SurrealDB:
       - Set `text_content = result.text`
       - Set `status = "extracting_text"` (Phase 7 uses this status — Phase 8 will add full transition)
    8. Update document chunk count: store a temporary `_page_count = result.page_count` on the document record for downstream use
    9. Return:
       ```python
       return {
           "document_id": document_id,
           "text_length": len(result.text),
           "page_count": result.page_count,
           "page_offsets": result.page_offsets,
       }
       ```
    10. Error handling: catch `ConnectionError` (SurrealDB or MinIO), `Exception`, return error dict matching existing activity pattern.

    **S3 object reading helper in MinIO:**
    The `get_storage()` is sync. Use `asyncio.to_thread()` to run the blocking I/O:
    ```python
    async def _get_blob_from_minio(blob_path: str) -> bytes:
        bucket = os.environ.get("MINIO_BUCKET", "eth-documents")
        def _fetch():
            with get_storage() as client:
                response = client.get_object(bucket, blob_path)
                data = response.read()
                response.close()
                response.release_conn()
                return data
        return await asyncio.to_thread(_fetch)
    ```

    @activity.defn
    async def chunk_document_activity(document_id: str, extraction_result: dict) -> dict:
        """Chunk a document's extracted text with page-provenance tracking.
        
        Takes the extraction result dict (from extract_text_activity) containing
        text_length, page_count, and page_offsets. Queries text_content from

        Returns:
            dict with document_id, chunks (list of chunk payloads), chunk_count
            dict with error on failure
        """

    Implementation:
    1. Connect to SurrealDB
    2. Query `text_content` from the document record
    3. Extract `page_offsets` from `extraction_result.get("page_offsets", [0])`
    4. Run DocumentChunker:
       ```python
       chunker = DocumentChunker()
       chunk_result = chunker.chunk(text, page_offsets)
       ```
    5. Build serializable chunk payloads:
       ```python
       chunks = []
       for c in chunk_result.chunks:
           chunks.append({
               "chunk_index": c.chunk_index,
               "text": c.text,
               "page_start": c.page_start,
               "page_end": c.page_end,
               "offset_start": c.offset_start,
               "offset_end": c.offset_end,
           })
       ```
    6. Update document status to "chunking" (Phase 7 status — Phase 8 will add full transition)
    7. Return:
       ```python
       return {
           "document_id": document_id,
           "chunks": chunks,
           "chunk_count": len(chunks),
       }
       ```
    8. Error handling: ConnectionError → error dict, Exception → error dict with status update to "failed"

    **Activity 3: `store_chunks_activity` (CHNK-05 part 2)**

    ```python
    @activity.defn
    async def store_chunks_activity(document_id: str, chunk_payload: dict) -> dict:
        """Store document chunk records in SurrealDB.
        
        **Idempotent:** First deletes any existing document_chunk records for
        this document, then inserts fresh chunks from chunk_payload["chunks"].
        
        Returns:
            dict with document_id, chunks_stored on success
            dict with error on failure
        """
    ```

    Implementation:
    1. Connect to SurrealDB
    2. `doc_ref = f"document:{document_id}"`
    3. Delete-then-recreate (same pattern as `store_extraction_results_activity`):
       ```python
       # Delete existing chunks
       await db.query(
           f"DELETE document_chunk WHERE document = $doc_ref",
           {"doc_ref": doc_ref},
       )
       
       # Insert new chunks
       chunks_data = chunk_payload.get("chunks", [])
       for chunk in chunks_data:
           await db.create(
               "document_chunk",
               {
                   "chunk_index": chunk["chunk_index"],
                   "text": chunk["text"],
                   "page_start": chunk["page_start"],
                   "page_end": chunk["page_end"],
                   "offset_start": chunk["offset_start"],
                   "offset_end": chunk["offset_end"],
                   "document": doc_ref,
               },
           )
       ```
    4. Update document status:
       - If chunks stored > 0: `status = "processed"` (Phase 7 keeps existing processed status — Phase 8 adds chunking status)
       - If chunks stored == 0: log warning but still update to "processed" (empty document with zero chunks is valid)
    5. Return:
       ```python
       return {
           "document_id": document_id,
           "chunks_stored": len(chunks_data),
       }
       ```
    6. Error handling: ConnectionError → error dict, Exception → error dict with status update to "failed"

    **Important:** Follow existing code patterns exactly:
    - Use `activity.logger` for all logging
    - Use `_db_params()` for SurrealDB connection parameters
    - Return error dicts on failure (don't raise exceptions)
    - All SurrealDB UPDATE statements use f-string `doc_ref` (SurrealDB v3 limitation)
    - Add `import asyncio, base64, io` at the top if not already present

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Temporal activity→SurrealDB | Activity connects to SurrealDB per invocation |
| Temporal activity→MinIO | extract_text_activity reads blob from MinIO |
| extract_text_activity→PdfExtractor | Untrusted PDF content parsed by extractor |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-05 | Denial of Service | extract_text_activity / MinIO blob read | mitigate | Large PDFs bounded by upload endpoint 50 MB limit; activity handles OSError during read gracefully |
| T-07-06 | Tampering | extract_text_activity — document is empty/scanned | mitigate | ExtractorQualityError catches this explicitly; activity returns error dict with actionable message, sets document status to "failed" |
| T-07-07 | Information Disclosure | document_chunk table stores chunk text | accept | Chunks contain subset of document text already accessible via GET /documents/{id} for authorized users |
| T-07-08 | Tampering | store_chunks_activity — delete-then-recreate partial failure | mitigate | Activity returns error dict on failure; document status set to "failed"; prior chunks are already deleted (consistent state) |
| T-07-09 | Elevation of Privilege | document_chunk.document record link | accept | Links are internal SurrealDB record references — no untrusted input controls the link value |

</threat_model>
