### Deferred Loading Pattern

```js
const deferredLoaders = {};
function deferredLoading(key, showFn, hideFn) {
  deferredLoaders[key] = setTimeout(showFn, 200);
  return { done: function() { clearTimeout(deferredLoaders[key]); hideFn(); } };
}
```

Applied identically to all four data tabs:
- `fetchDocuments`/`renderDocuments` with key `'docs'`
- `fetchEntities`/`renderEntities` with key `'entities'`
- `fetchReferences`/`renderReferences` with key `'refs'`
- `fetchLogs`/`renderLogs` with key `'logs'`
