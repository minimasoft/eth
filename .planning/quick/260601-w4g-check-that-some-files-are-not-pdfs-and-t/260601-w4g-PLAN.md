Modify the `extract_text_activity` function in `activities.py` at the point after document fields are read (line ~777, after `mime_type = doc.get("mime_type", "")`) and before the existing `# ---- Get binary content ----` section (line ~779).

After obtaining both `content` bytes and the document metadata (`filename`, `mime_type`), insert format detection:

1. **Derive format key** from `filename` extension (lowercased) and `mime_type`:
   - `.pdf` or `application/pdf` → format = `"pdf"`
   - `.txt` or `text/plain` → format = `"plain_text"`
   - `.md` or `text/markdown` → format = `"plain_text"`
   - No extension (`filename` has no `.` or suffix is empty) AND `mime_type` is empty or `text/plain` → format = `"plain_text"`
   - No extension AND `mime_type` is `application/octet-stream` or empty → format = `"plain_text"` (conservatively treat as text)
   - Everything else → format = `"unsupported"`

2. **Branch on format**:
   - **`"pdf"`** — Keep existing behavior: `PdfExtractor().extract(content, filename=filename)`, update document record with `text_content`, `status='extracting_text'`, `_page_count`, etc. Return existing success dict `{document_id, text_length, page_count, page_offsets}`.
   - **`"plain_text"`** — No PDF extraction needed:
     - Decode content as UTF-8 (with `errors='replace'` for safety). Store as `text`.
     - Build synthetic page data: `page_count = 1`, `page_offsets = [0, len(text)]`.
     - Update document record: `SET text_content = $text, status = 'extracting_text', _page_count = 1, updated_at = time::now()`.
     - Return `{"document_id": document_id, "text_length": len(text), "page_count": 1, "page_offsets": [0, len(text)]}`.
     - **This return shape is compatible with `chunk_document_activity`** which reads `page_offsets` from the extraction result dict.
   - **`"unsupported"`** — Return error:
     - Log a warning with `document_id`, `filename`, and `mime_type`.
     - Update document record: `SET status = 'failed', error_message = $msg, updated_at = time::now()` with message like `"Unsupported document format: {ext} (mime: {mime_type}). Only PDF and plain text are supported."`.
     - Return `{"error": $msg, "document_id": document_id}`.
     - The caller (workflow) will throw `RuntimeError` from the `if "error" in extraction_result` check (workflow line 145-146).

3. **Apply the quality gate only for the PDF branch.** Plain text doesn't need `_apply_quality_gate` — if the user uploaded a text file, it's valid by definition (even if empty).

Edge cases to handle:
- UnicodeDecodeError on text decode: catch and return error similarly to ExtractorQualityError path.
- Empty filename (no extension): treat as `"plain_text"` regardless of mime_type (conservative).
- Mime type `application/octet-stream` with `.pdf` extension: treat as PDF (extension wins when known).
</action>
