- **Issue:** Plan ground truth said "./src is volume-mounted into containers — code changes need only a container restart". `docker compose restart api` left `/geo/events` 404: the api service (docker-compose.yml:111) has **no volumes** — `/app/src` is baked into the image at build time.

### Intentional micro-decisions within plan spec

- `parse_bbox` returns `None` (not a tuple) when all four args are absent — the route needs the no-bbox case; type is `tuple | None`. Documented in the docstring; tested (`test_no_bbox_returns_none`).
- Popup date output is also `escapeHtml()`-wrapped: `formatEventDate()` returns the raw ISO string for unparseable input, so unescaped dates would be an XSS hole (T-MAP-02 hardening).
- `eventMapInitialLoad` guard additionally cleared in the 0-items and fetch-error paths, so the user's first manual pan isn't silently swallowed when no `fitBounds()` moveend ever fires.
