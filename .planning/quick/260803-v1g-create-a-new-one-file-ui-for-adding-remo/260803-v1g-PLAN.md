  <name>Create providers.html — LLM provider configuration UI with localStorage persistence</name>
  <files>src/eth_pipeline/static/providers.html</files>
  <action>
Create a standalone HTML file at `src/eth_pipeline/static/providers.html` that serves as the LLM provider management interface. This is the core deliverable — everything in one file (HTML + CSS + JS embedded).

**Structure:**
- Header: Same blue (#2563eb) header with "ETH — Espacio Tiempo Humanos" title, but add a back button to return to main UI at `/ui`
- Main content area with two sections:
  1. **Active Provider Card** — Shows the currently active config (provider name, model, masked API key). Include a "Change" button to select a different one.
  2. **Provider List** — Table showing all saved configs with provider type, model, masked API key, and action buttons (select as active, delete)

**CSS:** Follow existing patterns from index.html:
- Use the same color palette (#2563eb for primary, #f8fafc for card backgrounds, #e2e8f0 for borders)
- Same font stack (-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif)
- Reuse button styles (btn-primary, btn-outline, btn-icon) — copy the CSS classes directly from index.html
- Card-based layout with border-radius: 8px and subtle backgrounds

**JavaScript:**
- localStorage persistence using key `"llm_providers"` storing a JSON array of config objects
- Each config object has: `{ id (UUID-like string), provider, api_key, model, base_url?, active }`
- Default configs on first load: OpenRouter with `deepseek/deepseek-v4-flash-0731` model and empty API key field
- Add form: dropdown for provider type (OpenRouter/Anthropic/OpenAI), text input for API key, text input for model name, optional text input for base_url (only shown when OpenRouter is selected)
- Mask API keys in display (show first 4 chars + asterisks, e.g., "sk-****...")
- Delete confirmation via simple confirm() dialog before removing a config
- Banner notifications using the same pattern as index.html's showBanner function

**Provider-specific behavior:**
- OpenRouter: Show base_url field (default: https://openrouter.ai)
- Anthropic/OpenAI: Hide base_url field (uses standard /v1/chat/completions endpoint)

**Accessibility:** Use proper ARIA attributes, role="tablist" for navigation, aria-selected on active tab.

**No external dependencies** — everything must work as a standalone HTML file with no CDN or npm packages.
