<objective>
Fix three root causes discovered during mini_esma.md document log analysis:

1. **RecordID binding bug**: Activities use Python strings (`"document:{id}"`) as query parameters for `WHERE document = $ref` — SurrealDB v3 does NOT coerce strings to RecordID types, returning 0 rows silently. The fix: pass `RecordID("document", document_id)` objects everywhere.

2. **IN subquery failure**: `WHERE event IN (SELECT id FROM event WHERE document = ...)` subqueries return empty in SurrealDB v3 even with correct RecordID parameters. The fix: use dot notation `WHERE event.document = $doc_rid` which resolves the record edge directly.

3. **Workflow carries extraction result anti-pattern**: `create_event_canonical_entities_activity` and `resolve_entities_with_search_activity` both receive the full LLM extraction `result` dict through Temporal's serialization layer, but only use it for: (a) early-return on `len(events)==0`, and (b) logging the event count. Both already query the DB for actual data. The fix: remove `result` parameter — query DB for counts/logging.

Also: consolidate 6 test files (43 test cases) into one comprehensive E2E test with named entity content that exercises the full pipeline end-to-end, verifying events, references, event canonical entities, entity resolution, and processing logs in a single test run.

Purpose: Fix silent data loss bug where `create_event_canonical_entities_activity` and `resolve_entities_with_search_activity` return empty because queries find nothing despite data existing in DB.
Output: Corrected activities, simplified workflow, consolidated E2E test, deleted redundant test files.
</objective>

```typescript
export async function surrealQuery(query: string, vars?: Record<string, unknown>): Promise<any[]> {
  const body: Record<string, unknown> = { query };
  if (vars) body.variables = vars;
  const resp = await fetch(SURREAL_SQL_URL, {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "Accept": "application/json",
      "NS": SURREAL_NS,
      "DB": SURREAL_DB,
      "Authorization": "Basic " + Buffer.from(`${SURREAL_USER}:${SURREAL_PASS}`).toString("base64"),
    },
    body: JSON.stringify(body),
    signal: AbortSignal.timeout(10_000),
  });
  const json = await resp.json();
  // SurrealDB returns array of result objects; extract the first result
  return Array.isArray(json) ? json.flatMap((r: any) => r.result ?? []) : [];
}
```
