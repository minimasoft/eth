Implement `#s=<tab>` and `#s=<tab>&<key>=<val>` state in the inline app script.

1. `parseHash()`: read location.hash (strip leading '#'), split on '&', require the first pair to be `s=<tab>`; remaining pairs collected as options. Whitelist tabs: upload, documents, lineatiempo, mapa, eventos, logs (plus legacy names that now redirect: none — old default documents). Invalid/missing s → null.
2. `applyHash()`: on a valid tab, restore eventos options BEFORE switchTab — `view` ∈ {table, timeline} → set eventosViewMode and sync the view-toggle button .active classes (reuse the toggle-update code from the existing view-toggle click handler by extracting a small `setEventosView(mode, {refetch})` helper the click handler also calls); `doc` matching /^[A-Za-z0-9_-]+$/ → set eventosDocumentFilter and eventosDocFilter select value (populateEventosDocFilter already preserves current value); `event` matching /^[A-Za-z0-9-]+$/ → after switchTab, showEventDetail(event) in restore mode.
3. `syncHash()`: build the canonical hash from current state — active tab, and for eventos: view, doc (if set), event (if currentEventId) — and assign location.hash only when it differs from the current one. Maintain a module-level `suppressHashWrite` flag + `lastWrittenHash` so writes triggered by applyHash do not re-enter.
4. Wire writers: switchTab → syncHash (skipped when suppressing); setEventosView → syncHash; eventosDocFilter change handler → syncHash; showEventDetail → syncHash (includes event=<id>); hideEventDetail → syncHash (drops event).
5. `window.addEventListener('hashchange', …)`: if location.hash === lastWrittenHash, reset flag and return; else parse + applyHash(). Browser back from an event detail then closes the detail; back across tabs switches tabs.
6. On load: keep the existing `switchTab('documents')` then call applyHash() so a deep link (e.g. #s=eventos&view=table&doc=abc123 or #s=eventos&event=<id>) restores state. When the hash has no `s=` (plain load), leave as-is (no hash write on first paint).
7. Guard logs: applyHash only switches to logs if logsDocumentId is set (same rule as onTabClick).
8. Never build HTML from hash values — values only flow into comparisons and select.value / showEventDetail(eventId) which already uses encodeURIComponent on fetch paths.
9. Extend tests/test_hash_navigation.py: parseHash/applyHash/syncHash identifiers exist; hashchange listener registered; whitelist constant present; `setEventosView` extracted and used by both the toggle handler and applyHash; showEventDetail/hideEventDetail update the hash (grep for syncHash calls inside them).
