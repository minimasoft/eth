## Tech Debt Items

### 1. Activity `_normalize` missing combining-mark stripping (TECH-DEBT)

- **File:** `src/eth_pipeline/activities.py:697`
- **Issue:** `_normalize` uses `unicodedata.normalize("NFD", text).casefold()` but does NOT strip combining marks. This means `"José"` normalizes to `"jose\u0301"` while `"Jose"` normalizes to `"jose"` — they will NOT match as equal despite being the same name.
- **Test helper fix exists:** `tests/test_search_first_resolution.py` has `"".join(c for c in nfd if not unicodedata.combining(c))` as a fix.
- **Disposition:** Fix in follow-up plan. Exact-match accuracy degraded for accented Spanish text (common in legal documents: José, María, Álvaro, etc.).
