<objective>
Fix full cascade deletion of documents so that deleting a document (or clearing its events) cleans up ALL associated records: references, events, event_entity_link edges, document_event_log entries, and document_chunks. No orphan references, orphan events, orphan links, or orphan log entries remain.

Purpose: The current delete endpoint passes string `"document:{id}"` as SurrealDB DELETE query parameters, which SurrealDB v3 cannot properly bind against `record<document>` fields. This leaves orphan references, events, entity links, and processing log entries behind. The fix uses `RecordID` objects (already used successfully in SELECT queries) and adds the three missing cleanup steps (`event_entity_link`, `document_event_log`).

After fixing, simplify the test suite: remove small/simple fragment checks from pipeline_v4.test.ts that consume time/tokens but add minimal coverage, and add a single comprehensive cascade-delete E2E test that proves zero orphans.

Output: Fixed `documents.py` + simplified cascade-delete E2E test in `pipeline_v4.test.ts`.
</objective>
