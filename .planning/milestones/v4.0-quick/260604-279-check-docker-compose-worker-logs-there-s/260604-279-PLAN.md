  <action>
Inspect the live pipeline state with these commands:

1. **Worker logs (full):** `docker compose logs worker --tail=1000` — capture all error patterns, timestamps, document IDs.
2. **SurrealDB health:** `docker compose logs surrealdb --tail=100` — check for persistence issues, connection errors.
3. **Temporal workflow state:** `docker compose exec temporal-server temporal workflow list` — list all workflows and their statuses.
4. **Document status via API:** `curl http://localhost:1985/documents` and `curl http://localhost:1985/documents?status=failed` — check what documents exist and their current status.
5. **Check if fix is live in container:** `docker compose exec worker grep -n "ref_type not in" /app/src/eth_pipeline/activities.py` — confirm the 260604-1px validation code is deployed.

Categorize every error/issue found into:
- **Live bug:** Code error on current (post-fix) code path, affecting new workflow runs
- **Stale replay:** Temporal replay of a pre-fix workflow history (fix is deployed but old history has the error stored)
- **Resolved:** Previously reported issue that is no longer occurring
- **Observation:** Informational finding, not a bug

Count `ProcessingLogger` occurrences in worker logs to verify I-01 is resolved (expected: 0 errors).
</action>
