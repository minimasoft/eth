# Quick Task 260604-3x3: Fix RecordID Binding, IN Subqueries, and Consolidate Tests

**Fix RecordID binding and IN subquery bugs causing silent data loss in event entity creation and entity resolution, plus consolidate 6 test files into one comprehensive E2E test**

## Accomplishments

- Fixed RecordID binding bug: all WHERE `document = $doc_rid` parameters use `RecordID("document", id)` objects instead of string `f"document:{id}"` — eliminates SurrealDB v3 silent 0-row returns
- Replaced all IN subqueries (`WHERE event IN SELECT id FROM event WHERE document = $doc_ref`) with dot notation (`WHERE event.document = $doc_rid`) — SurrealDB v3 resolves record edges directly
- Removed `result` parameter from `create_event_canonical_entities_activity`, `resolve_entities_with_search_activity`, and `resolve_entities_activity` — activities now query event count from DB directly, eliminating unnecessary Temporal payload serialization
- Consolidated 6 test files (43 test cases) into one comprehensive E2E test with 10 sequential steps, using a rich Spanish criminal case document with named entities
