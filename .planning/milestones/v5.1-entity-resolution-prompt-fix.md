# v5.1: Entity Resolution Prompt & Batching Fix

**Goal:** Fix LLM context overflow in entity resolution by removing full document text from prompts, adding reference-only batching, and decoupling entity grouping (LLM) from DB dedup (code).

**Why this milestone:** The current `resolve_entities_with_search_activity` sends the entire `text_content` (up to 400K+ chars / ~100K tokens) as `document_context` in the LLM resolution prompt. This causes context window overflows and LLM failures. Additionally, the LLM is asked to match against existing entities, which is better done code-side for reliability and cost.

## Phase 23: Entity Resolution Prompt & Batching

**Depends on:** Nothing (self-contained fix)

**Requirements:**
- RES-01: LLM resolution prompts must NOT include the full document text
- RES-02: Only reference `verbatim_text` snippets are included as context
- RES-03: If estimated prompt exceeds ~240K tokens, references are processed in batches
- RES-04: Entity grouping is done by LLM; DB deduplication is done by code
- RES-05: Both `resolve_entities_with_search_activity` and `resolve_entities_activity` are updated

**Schema changes needed in `llm.py`:**
- New `ENTITY_GROUPING_SCHEMA` — LLM receives references (verbatim_text only) and returns entity groups with inferred name/type
- Remove `document_context` and `existing_entities` from `_build_resolution_payload`
- Add `_estimate_tokens(text: str) -> int` (crude: len/4 for Spanish)
- Add `_batch_references(references, max_tokens) -> list[list]` — split into token-sized batches

**Activity changes in `activities.py`:**
- `resolve_entities_with_search_activity`:
  - Drop the full-document `SELECT text_content` query
  - Nullify prior links (replay safety — kept)
  - Exact-match pass (NFD+casefold) against existing DB entities (kept)
  - Group remaining refs by `reference_type`
  - For each type: estimate tokens → batch if needed → LLM groups → DB dedup per batch
  - DB dedup: for each LLM entity, NFD+casefold match on existing names → fuzzy CONTAINS match → create new
- `resolve_entities_activity` (older version): same treatment
